# Four Points Green Power — Official Website

Solar energy and green power solutions for homes, businesses, and communities across Ghana.

**Website:** [www.fourpointsgreen.com](https://www.fourpointsgreen.com)
**Company:** Four Points Green Power Ltd
**Location:** 3rd Floor, Ampomaah House, Roman Ridge, Accra, Ghana

## About This Repository

This repository contains the source code and content for the Four Points Green Power website.

**Stack:**
- **Hosting:** Netlify (free tier)
- **Admin Dashboard:** Decap CMS at `/admin`
- **Domain:** fourpointsgreen.com (via Namecheap)
- **Design:** Custom, brand-aligned single-page website

## For Site Administrators

To edit content on the website:

1. Visit [www.fourpointsgreen.com/admin](https://www.fourpointsgreen.com/admin)
2. Log in with your registered email
3. Edit content using the visual editor
4. Click "Save" — changes go live in about a minute
